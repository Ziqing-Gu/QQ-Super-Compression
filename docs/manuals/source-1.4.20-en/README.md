# English manual 1.4.20

Matches the approved Chinese 1.4.20 edition, retaining its established 49-page chapter order and the English Segoe UI typography. Use `build_manual_1_4_20_en.py` with `--output <output-dir> --captures ../source-1.4.20-zh/assets --theme-images ../source-1.4.20-zh/assets --fonts <font-directory>` (adjust paths to the working directory). Fonts: segoeui.ttf, seguisb.ttf, msyh.ttc and msyhbd.ttc. Supply fonts from your licensed system installation; they are not redistributed. Python dependencies: reportlab, Pillow, pypdf. Render and inspect the PDF before delivery.
