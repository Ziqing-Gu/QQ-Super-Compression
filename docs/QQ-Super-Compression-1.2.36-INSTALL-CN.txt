QQ Super Compression 1.2.36 - 安装说明
厂商：Qing Audio | 版本：1.2.36 | 文档日期：2026-10-01

适用系统：Windows 10/11 64 位；macOS 11.0 或更新版本。
本包只有一个插件。VST3 与 AU 是两套独立格式，请只安装宿主实际需要的格式。
已安装的各格式请一起升级到 1.2.36。本用户包不含源码；项目采用 Qing Audio 非商业源码共享许可证，禁止商业使用。分发时须同时免费公开完整对应源码，保留署名、许可证和来源，并注明修改。
本产品是 QQ Super Compression（超级压缩），不是 QQ Super Multiband Compression（超级分段压缩）。
源码和许可证公开于：https://github.com/Ziqing-Gu/QQ-Super-Compression
升级前请备份工程和现有插件 bundle。随附中文和英文用户手册均为 1.2.36，各 41 页，包含本版本 Limiter 和过采样用法。
本次提供 Windows x64 VST3、macOS Apple Silicon VST3、Intel VST3 和 Universal 2 AU 四类成品。

一、选择正确的压缩包

Windows 64 位宿主：
Win/QQ Super Compression 1.2.36 Windows x64 VST3.zip

Apple Silicon 原生宿主（arm64）：
Mac/QQ Super Compression 1.2.36 macOS Apple Silicon VST3.zip

Intel Mac，或 Apple Silicon 上以 Rosetta 运行的 Intel 宿主（x86_64）：
Mac/QQ Super Compression 1.2.36 macOS Intel x86_64 VST3.zip

Logic Pro 或其他 AU 宿主：
Mac/QQ Super Compression 1.2.36 macOS Universal 2 AU.zip

Universal 2 AU 同时包含 arm64 和 x86_64。两个 macOS VST3 架构包只能选择一个，以宿主的实际运行架构为准，不要同时安装 Apple Silicon 和 Intel VST3。

二、Windows x64 VST3 安装与升级

1. 完全退出 Cubase、Nuendo、REAPER、Studio One 以及其他会加载或扫描插件的宿主，并确认后台扫描进程已经结束。
2. 解压 Win/QQ Super Compression 1.2.36 Windows x64 VST3.zip。
3. 解压后应得到完整文件夹：
   QQ Super Compression.vst3
   这是一个 VST3 bundle。不要只复制 Contents 里的二进制文件，也不要改名。
4. 打开系统 VST3 目录：
   C:\Program Files\Common Files\VST3
   写入此目录通常需要管理员确认。
5. 升级时，先把扫描目录中旧的同名“QQ Super Compression.vst3”完整移出并保存为回滚副本，再把新版完整 bundle 复制进去。不要在任何扫描目录里同时保留旧版和新版，也不要在其他自定义 VST3 目录留下重复副本。
6. 重新打开宿主，在插件管理器中执行完整 VST3 重新扫描；可在 Qing Audio 厂商分类或按产品名查找。
7. 如果插件未出现：确认宿主为 64 位、bundle 复制完整且没有重复副本；在宿主中清除失败/黑名单记录后重新扫描。必要时重启宿主或 Windows。若提示缺少运行库，请安装 Microsoft 官方 Visual C++ 2015-2022 x64 Redistributable。

三、macOS VST3 安装与升级

1. 完全退出所有宿主和插件扫描程序。
2. 按宿主架构选择一个 VST3 ZIP：原生 Apple Silicon 宿主使用 Apple Silicon 包；Intel Mac 或 Rosetta Intel 宿主使用 Intel x86_64 包。不要同时安装两套 VST3。
3. 解压所选 ZIP，应得到完整 bundle：
   QQ Super Compression.vst3
4. Finder 中选择“前往 -> 前往文件夹”，输入：
   ~/Library/Audio/Plug-Ins/VST3
   用户 Library 默认隐藏；也可以按住 Option 打开 Finder 的“前往”菜单并选择“资源库”。目录不存在时可以创建。
5. 把完整 bundle 复制到上述用户目录。若要供所有用户使用，可改装到：
   /Library/Audio/Plug-Ins/VST3
   系统目录通常需要管理员权限。用户目录和系统目录只能保留一份。
6. 升级或切换原生/Rosetta 宿主时，先把旧的同名 bundle 移出所有扫描目录，再复制新版。不要把两种架构并排安装。
7. 重新打开宿主并执行 VST3 重新扫描。仍未识别时，先检查宿主架构、重复副本和 macOS 安全提示，再重启宿主或电脑。

四、macOS Audio Unit（AU）安装与升级

1. 完全退出所有宿主和插件扫描程序，再解压 Mac/QQ Super Compression 1.2.36 macOS Universal 2 AU.zip。
2. 解压后应得到完整 bundle：
   QQ Super Compression.component
3. 把完整 bundle 复制到：
   ~/Library/Audio/Plug-Ins/Components
   或供所有用户使用的：
   /Library/Audio/Plug-Ins/Components
   系统目录可能需要管理员权限。两个目录只能保留一份。
4. Universal 2 AU 同时包含 Apple Silicon arm64 和 Intel x86_64。AU 与 VST3 相互独立；只使用 AU 的宿主不需要另外安装 VST3。
5. 升级时先把旧的同名 .component 移出扫描目录并保存，再复制新版。
6. 重新打开 Logic Pro，在“设置/偏好设置 -> 插件管理器”中选中本插件，执行“重置并重新扫描所选项”。其他 AU 宿主使用各自的重新扫描功能；必要时重启电脑。

五、macOS 安全提示与加载失败处理

本次 macOS 成品采用 ad-hoc 签名，未经过 Apple Developer ID 签名及 Apple 公证。下载隔离标记可能使 macOS 在首次加载时阻止插件。

先在“系统设置 -> 隐私与安全性”查看是否出现允许加载提示。只有确认文件来自可信交付包时，才可在终端中针对已安装的单个 bundle 执行以下对应命令：

用户 VST3 目录：
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/QQ Super Compression.vst3"

用户 AU 目录：
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/QQ Super Compression.component"

若安装在系统目录，请把路径替换为实际的 /Library/Audio/Plug-Ins/VST3 或 /Library/Audio/Plug-Ins/Components，并仅在权限确实需要时使用 sudo。只对上面列明的完整 bundle 操作，不要对整个磁盘或 Library 目录解除隔离；来源不确定时不要执行。

执行后重新打开宿主并重新扫描。仍失败时检查宿主架构、重复副本和安装路径，必要时重启电脑。不要关闭系统整体安全保护。

六、升级到 1.2.36 Stable

1. 升级前另存工程副本，并保存原版本的完整 .vst3 或 .component bundle，以便回滚。
2. 按“关闭宿主 -> 移出旧同名 bundle -> 复制 1.2.36 bundle -> 重新扫描”的顺序操作。插件身份保持不变；升级后请确认旧工程加载、参数状态和自动化。
3. Full/Eco 按插件实例保存；停止播放后的静音处理经过优化，恢复输入时在音频处理回调内恢复完整处理。实际 ASIO-Guard 表现仍取决于宿主工程和设备。
4. Limiter 的 0 ms Lookahead 过采样提供 1x / 4x / 8x / 16x；Ceiling Hard Clipper 和 True Peak 提供 4x / 8x / 16x。升级时保留旧状态和自动化的档位含义。
5. 随附两本 1.2.36 用户手册已更新 Limiter、0 ms Lookahead 和双压建议。请按手册检查 Limiter、Single/Dual、A/B、Output LINK 和已有自动化，并在自己的宿主中试听。
6. 如需回滚，关闭宿主，移出 1.2.36 bundle，恢复先前保存的原版本 bundle，再执行完整重新扫描并打开升级前保存的工程副本。

七、兼容性、首次扫描与排查

- Windows 仅提供 x64 VST3；macOS 最低版本为 11.0。
- Apple Silicon 原生宿主使用 arm64 VST3；Intel 或 Rosetta 宿主使用 x86_64 VST3；Universal 2 AU 同时包含两种架构。
- 同一格式不要在用户目录、系统目录或自定义扫描目录中留下重复副本。
- 插件未出现时，先核对 ZIP 文件名、bundle 名称、安装路径、宿主位数/架构和安全提示，再执行完整重新扫描；最后才重启宿主或电脑。
- 不需要额外安装程序。不同宿主、设备路由和长期工程可能存在差异，本说明不替代用户在自己的宿主中试听和确认。
- 禁止商业使用。分发原版或修改版时，须免费提供完整对应源码，保留作者、许可证和来源，并注明修改；具体条款以仓库许可证为准。
