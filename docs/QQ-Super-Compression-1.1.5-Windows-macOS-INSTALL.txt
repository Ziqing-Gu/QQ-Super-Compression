This package contains one plug-in: QQ Super Compression. Keep every installed format at version 1.1.5. Quit Cubase, Nuendo, REAPER, Studio One, Logic Pro, and any other host that may scan plug-ins before upgrading.

Main changes since v1.0.4
1. v1.1.0 adds optional mono/stereo external sidechain input, INT/EXT Source, dedicated Key Gain, Key Level, and SC LISTEN. The external key replaces only the detector and never enters the normal audible output.
2. v1.1.1 adds a default-OFF, 20-500 Hz detector-only HPF. EXT order is Key Gain -> HPF; the filtered key feeds the detector, Key Level, and SC LISTEN without filtering the carrier.
3. v1.1.2 makes product-facing Gain Reduction include Mix. The right-side GR meter, two-second Hold, and historical Display use the same Mix-aware definition. The visible Wet pre-Makeup trace is removed; the Display shows Dry/Input, GR including Mix, and Output post-Mix, and reprojects visible history when current controls change.
4. When EXT is available, a soft contour shows the post-Key-Gain/post-HPF external key. LIGHT and CLASSIC remain identical in function, parameters, and sound.
5. v1.1.3 makes Key Gain reproject the complete visible history in real time and replays raw Key history at low priority after the HPF knob is released.
6. v1.1.4 adds HPF-history retries, shorter debounce, domain-limited replay work, and the HPF UPDATING indicator.
7. v1.1.5 advances the Display to 60 Hz / 480 points, caches projections and paths, and uses bounded sparse GR shading plus opaque child painting to remove deep-compression stalls. Audio DSP, parameters, and state schema 10 are unchanged.

Windows x64 VST3
1. Quit Cubase, Nuendo, REAPER, Studio One, and every other host that may scan plug-ins.
2. Extract `QQ Super Compression 1.1.5 Windows x64 VST3.zip`. Its root should contain `QQ Super Compression.vst3`.
3. Inspect `C:\Program Files\Common Files\VST3`. If an older same-name `QQ Super Compression.vst3` exists, delete the old bundle or fully replace it while every DAW is closed. Do not retain a duplicate in another VST3 directory.
4. Copy the new `QQ Super Compression.vst3` to `C:\Program Files\Common Files\VST3`. Administrator permission may be required.
5. Reopen the host and run a VST3 rescan. If the plug-in is still missing, quit the host, clear its plug-in cache or restart the computer, and scan again.

macOS VST3
1. Quit the host. Choose arm64 for Apple Silicon/M-series Macs or x86_64 for Intel Macs. Install only one VST3 architecture package; do not install both.
2. Extract the selected ZIP. Its root should contain `QQ Super Compression.vst3`.
3. Remove an older same-name bundle from the user or system location so duplicate copies do not remain.
4. Copy the new bundle to `~/Library/Audio/Plug-Ins/VST3`; `/Library/Audio/Plug-Ins/VST3` is the optional system location and normally requires administrator permission. In Finder, hold Option while opening Go to reveal the user Library.
5. Reopen the host and rescan VST3 plug-ins; restart the computer if necessary.

macOS Audio Unit
1. Quit Logic Pro or any other AU host. `QQ Super Compression 1.1.5 macOS Universal 2 AU.zip` contains both arm64 and x86_64.
2. Its root should contain `QQ Super Compression.component` after extraction.
3. Remove an older same-name component from the user or system location, then copy the new component to `~/Library/Audio/Plug-Ins/Components`; `/Library/Audio/Plug-Ins/Components` is the optional system location.
4. AU and VST3 are separate formats. Install only the format you need, then reopen Logic Pro or rescan Audio Units. Restart the computer if necessary.

macOS security and load failures
The macOS artifacts are produced by GitHub Actions with ad-hoc signing and are not Apple Developer ID notarized. macOS may block the first load because of quarantine or signing policy. First verify that the files came from the repository and v1.1.5 build above, then use the actual installed path, for example:
`xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/QQ Super Compression.vst3"`
For AU:
`xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/QQ Super Compression.component"`
Reopen the host and rescan afterward; restart the computer if necessary. Never remove quarantine from files whose source you do not trust.

Compatibility, upgrades, and troubleshooting
- Do not retain duplicate copies in both user and system plug-in locations, and do not keep an old same-function version alongside the new version.
- Full upgrade order: close every DAW -> remove the old same-name bundle -> copy the new bundle -> reopen and rescan.
- External sidechain operation depends on host Sidechain bus support and routing. A missing or silent EXT key produces 0 dB GR while the carrier remains audible.
- SC LISTEN is a temporary detector-key audition state. It is not automated, saved, or included in A/B, and turns off when the sidechain panel or editor closes.
- HPF defaults to OFF, so legacy projects retain v1.1.0 full-band detector behaviour. When enabled, it changes detector frequency weighting only.
- v1.1.2 adds no sound parameter and keeps state schema 10. Mix-aware GR and history reprojection update the visual explanation without changing the established compression audio DSP.
- If the host still uses an old cache, quit it fully, clear the plug-in cache, and rescan.
