本版变化
1. 右上角新增 LIGHT / CLASSIC 主题切换。
2. LIGHT 保留暖色 ivory 界面；CLASSIC 使用较低亮度的 charcoal / cyan 控件风格。
3. 两种主题保持相同布局、参数、自动化和声音；插件会在本机保存并恢复上次选择的主题。

包选择
- Windows x64 VST3：Win\QQ Super Compression 1.0.4 Windows x64 VST3.zip
- Apple Silicon / M 系列 Mac VST3：Mac\QQ Super Compression 1.0.4 macOS Apple Silicon VST3.zip
- Intel Mac VST3：Mac\QQ Super Compression 1.0.4 macOS Intel x86_64 VST3.zip
- Universal 2 AU：Mac\QQ Super Compression 1.0.4 macOS Universal 2 AU.zip
- Linux、AAX 和独立应用：不提供。

Windows x64 VST3
1. 完全退出 Cubase、Nuendo、REAPER、Studio One 及其他可能扫描插件的宿主。
2. 解压 QQ Super Compression 1.0.4 Windows x64 VST3.zip；根层应得到 `QQ Super Compression.vst3`。
3. 将该 bundle 复制到 `C:\Program Files\Common Files\VST3`。系统可能要求管理员权限。
4. 如已有旧版同名 `QQ Super Compression.vst3`，先在 DAW 完全关闭时覆盖它；不要在不同 VST3 目录保留两个同名版本。
5. 重新打开宿主并执行 VST3 rescan；如果未出现，请重启宿主或清除宿主的插件缓存后重新扫描。

macOS VST3
1. 完全退出宿主。只选择一个 VST3 架构包：Apple Silicon/M 系列选择 arm64，Intel Mac 选择 x86_64；不要同时安装两套。
2. 解压后应得到 `QQ Super Compression.vst3`。
3. 复制到 `~/Library/Audio/Plug-Ins/VST3`；也可使用系统目录 `/Library/Audio/Plug-Ins/VST3`（通常需要管理员权限）。Finder 中按住 Option 点击“前往”可显示用户 Library。
5. 重新打开宿主并重新扫描 VST3；必要时重启电脑。

macOS Audio Unit
1. 完全退出 Logic Pro 或其他 AU 宿主。QQ Super Compression 1.0.4 macOS Universal 2 AU.zip 同时包含 arm64 与 x86_64。解压后应得到 `QQ Super Compression.component`。
2. 复制到 `~/Library/Audio/Plug-Ins/Components`；系统目录为 `/Library/Audio/Plug-Ins/Components`。
3. AU 与 VST3 是独立格式，只安装需要的格式，然后重新打开 Logic Pro 或重新扫描 Audio Units。

macOS 安全提示
macOS 成品为 CI 生成的 ad-hoc 签名包，不是 Apple Developer ID 公证版本。确认来源可信后，如 Gatekeeper 隔离插件，可对实际 bundle 路径执行：
`xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/QQ Super Compression.vst3"`
或把路径替换为实际 AU component 路径。不要对来源不明的文件执行解除隔离命令。

兼容性与排错
- 确保不要同时在用户与系统目录保留重复副本，也不要保留旧版同功能插件。
- 如果宿主加载旧缓存，完全退出宿主后重新扫描。
- 主题只影响外观，不影响 DSP、参数、宿主自动化、A/B、工程状态或声音；新版本会在本机恢复上次选择的 LIGHT/CLASSIC 主题。
- 旧工程继续保留原有压缩、Threshold、LINK、Mix、Lookahead、Oversampling、PDC 与 Bypass 行为。
