本包只有一个插件：QQ Super Compression。所有已安装格式必须保持同一版本 1.2.0。升级前必须完全退出 Cubase、Nuendo、REAPER、Studio One、Logic Pro 和其他可能扫描插件的宿主。

1.2.0 主要变化
Single 支持 1/32–32 的 Ratio 与默认 OFF 的 Range 上截止；Dual 提供 Up / Down 两个 Ratio 和相对 Ratio LINK。上压只提升 UP 门槛以上且 DOWN 以下的部分；超过 DOWN 后只下压。所有 Ratio 默认 1:1；Dual 默认 UP=-inf、DOWN=0 dB。边界重合停止动态处理。新版中英文手册各 23 页。

升级提醒：已保存 Ratio 数值保留，但 Single Ratio 的旧归一化自动化映射因范围扩展而改变。保留工程副本并核对自动化。

包选择
- Windows x64 VST3：Win\QQ Super Compression 1.2.0 Windows x64 VST3.zip
- Apple Silicon / M 系列 Mac VST3：Mac\QQ Super Compression 1.2.0 macOS Apple Silicon VST3.zip
- Intel Mac VST3：Mac\QQ Super Compression 1.2.0 macOS Intel x86_64 VST3.zip
- Universal 2 AU：Mac\QQ Super Compression 1.2.0 macOS Universal 2 AU.zip
- Linux、AAX 和独立应用：不提供。

Windows x64 VST3
1. 完全退出 Cubase、Nuendo、REAPER、Studio One 及其他可能扫描插件的宿主。
2. 解压 `QQ Super Compression 1.2.0 Windows x64 VST3.zip`；ZIP 根层应得到 `QQ Super Compression.vst3`。
3. 检查系统目录 `C:\Program Files\Common Files\VST3`。如存在旧版同名 `QQ Super Compression.vst3`，在 DAW 完全关闭时删除旧 bundle 或用新版完整覆盖；不要在其他 VST3 目录保留重复副本。
4. 将新版 `QQ Super Compression.vst3` 复制到 `C:\Program Files\Common Files\VST3`。系统可能要求管理员权限。
5. 重新打开宿主并执行 VST3 rescan。如果插件仍未出现，完全退出宿主、清除其插件缓存或重启电脑后再次扫描。

macOS VST3
1. 完全退出宿主。Apple Silicon/M 系列 Mac 选择 arm64 包；Intel Mac 选择 x86_64 包。只安装一个 VST3 架构包，不要同时安装两套。
2. 解压所选 ZIP；根层应得到 `QQ Super Compression.vst3`。
3. 删除用户目录或系统目录中旧版同名 bundle，避免重复副本。
4. 将新版复制到 `~/Library/Audio/Plug-Ins/VST3`；也可使用系统目录 `/Library/Audio/Plug-Ins/VST3`（通常需要管理员权限）。Finder 中按住 Option 点击“前往”可显示用户 Library。
5. 重新打开宿主并重新扫描 VST3；必要时重启电脑。

macOS Audio Unit
1. 完全退出 Logic Pro 或其他 AU 宿主。`QQ Super Compression 1.2.0 macOS Universal 2 AU.zip` 同时包含 arm64 与 x86_64。
2. 解压后根层应得到 `QQ Super Compression.component`。
3. 删除用户目录或系统目录中的旧版同名 component，再复制新版到 `~/Library/Audio/Plug-Ins/Components`；可选系统目录为 `/Library/Audio/Plug-Ins/Components`。
4. AU 与 VST3 是独立格式，只安装需要的格式。重新打开 Logic Pro 或重新扫描 Audio Units；必要时重启电脑。

macOS 安全与加载失败处理
macOS 成品由 GitHub Actions 生成，未经过 Apple Developer ID 签名或公证。两个 VST3 包为 ad-hoc 签名；Universal 2 AU 的 arm64 切片带 ad-hoc 签名，x86_64 切片没有嵌入签名。AU 已通过 Apple Silicon 构建机的 auval，Intel AU 尚未进行宿主实测。系统可能因为 quarantine 或签名政策阻止首次加载。先确认文件来自上述公开仓库和 v1.2.0 构建，再按实际安装路径执行：
`xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/QQ Super Compression.vst3"`
AU 可使用：
`xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/QQ Super Compression.component"`
执行后重新打开宿主并重新扫描，必要时重启电脑。不要对来源不明的文件解除隔离。

兼容性、升级与排错
- 不要在用户目录和系统目录同时保留重复副本，也不要同时保留旧版和新版同功能插件。
- 完整升级顺序：关闭 DAW -> 删除旧同名 bundle -> 复制新版 -> 重新打开并扫描。
- 外部侧链依赖宿主提供并路由 Sidechain bus。未连接或静音 EXT 时 GR 为 0，主载波保持可听。
- SC LISTEN 仅用于临时试听检测 Key；它不自动化、不保存、不进入 A/B，关闭侧链面板或编辑器时自动关闭。
- HPF 默认 OFF，因此旧工程保持 v1.1.0 全频 detector 行为；开启后只改变 detector 频率权重。
- 如宿主仍加载旧缓存，完全退出宿主并清除插件缓存后重新扫描。

Rev4 补充：有限 Range 与上压门槛内侧采用连续增益过渡，原有 Lookahead 延迟不变。Dual 的 Up / Down Ratio 旁各有独立 ON/OFF，默认 ON，使用 10 ms Crossfade 并同步更新 Display，随工程和 A/B 保存。关闭一支保留数值，也不会扩大另一支的作用范围。两本已完成的 23 页手册原样保留；新增行为详见 Release 更新说明。
