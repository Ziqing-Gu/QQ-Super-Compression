# Reproduce 1.2.8

Requires Windows x64, Visual Studio 2022 C++ Build Tools and Windows SDK, CMake 3.22+, and JUCE 8.0.15. Use a local JUCE 8.0.15 checkout or the repository's pinned FetchContent option.

For an explicitly requested Windows rebuild, use a fresh checkout and run `BUILD_WINDOWS.ps1 -JucePath <JUCE-8.0.15-checkout> -BuildDirectory D:/Codex/Temp/<new-build-dir>`. The helper configures the 1.2.8 source, builds the Windows VST3 and runs the real JUCE Limiter continuity regression. Plan C reuses the accepted Windows output; do not read or refresh frozen Plan B backups.

For broader local verification, build and run `QQSCLimiterCheck`, `QQSCUnityCheck` and `QQSCLoudnessCheck` with output directories on D:. The 1.2.8 Plan A record is `PLAN_A_WINDOWS_1.2.8.json`. The actual 1.2.7-to-1.2.8 VST3 comparison is recorded in the external Plan A evidence; historical binaries are not required to compile the release.

The accepted Windows binary is reused from the verified Plan A output for Plan C; Windows Actions is optional and is not triggered by default. Toolchain changes may produce different binary hashes. Universal 2 AU passed in run `36352181159` at public commit `a281cd9700b57d29378820b8fdb1fd9080e72767`. Intel VST3 uses commit `9ca6e6ff284dc133d7c7ecd3137861c6fc314093` (run `36353856702`); Apple Silicon VST3 uses `f5891559f24d54abe272d37d2941cdb1e068ba89` (run `36354377015`). All three have identical production source, assets and CMake. Later commits correct test-only floating-point preservation, the macOS undo shortcut and architecture selection. Output preservation is tested with exact stored-value equality; Ceiling zero allows less than 0.00001 dB rounding, and reset/redo must exactly restore the stored default. Use workflow inputs `vst3_only` and `vst3_arch` to reuse already verified packages only when production inputs are identical. Plan C includes desktop delivery; Plan D is the separately authorized formal GitHub Release.

Historical manuals and screenshots are retained as revision sources. The 1.2.7 bilingual manuals describe the established feature set but do not include the 1.2.8 continuity fix; README and `RELEASE_NOTES_1.2.8.md` are the current supplement.
